# 大乱斗换英雄响应与卡片刷新优化

## 功能概述

改进大乱斗换英雄和重掷的响应解析，避免成功的空响应触发重试；自动抢选检查接口错误；减少备选池卡片刷新时的闪烁。

## 实现步骤

1. connector 新增响应解析辅助方法：204 返回空字典，兼容非 JSON 响应，并为 HTTP 错误补充 errorCode 和 message。
2. benchSwap 和 reroll 使用该方法，避免成功操作因 JSON 解析异常重复发送。
3. 自动抢选检测返回的 errorCode，仅在成功后设置 swapped。
4. 备选池按英雄及目标格增量调整布局，删除失效卡片，仅移动位置变化的卡片。
5. 移除其他卡片的锁定透明效果，仅为操作中的卡片显示加载动画；窗口入口继续通过 _swapping 防止并发换人。仅在提示内容改变时更新 tooltip。

## 遇到的问题及解决方案

- 成功接口可能返回 204，无条件解析 JSON 会触发 retry；通过空响应兼容处理解决。
- 接口返回错误字典时，原自动抢选仍记录成功；增加错误检查。
- 清空并重建布局、改变整排透明度会增加刷新；采用增量布局及单卡加载状态。
- 当前终端找不到 python，py -0p 也未发现已安装解释器。按要求尝试 python main.py 后启动失败，未能完成应用启动及真实 LCU 行为验证。

## 经验总结

- 对有副作用的请求，应区分请求失败和成功响应解析失败，避免重复操作。
- 复用控件时同时减少不必要的布局与状态更新。
- 接口返回的业务错误需要在调用方确认后再推进本地状态。
