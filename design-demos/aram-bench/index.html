状态与交互

  • 六种状态：等待上架 / 就绪 / 正在更换 / 抢选成功 / 更换失败 / 倒计时告急； 切换时整窗内容一起换。
  • 点卡片 = 模拟 benchSwap：该卡 spinner、其它卡锁定， 约 950ms 后从池中移除并切成功态。
  • 抢选成功跨过 5/6 位时窗口高度跳档（358 ↔ 448）；实机窗口锚在 客户端右下角，应保底边不动、只改顶边。
  • 自动抢选开关可点，状态与界面同步。
  • 倒计时：数字按「剩余秒数取整」每秒变；环用 Web Animations 线性推进，文字从同一个动画时钟读数；≤10 秒环与数字转琥珀； 归零后提示「选人时间已结束」。
  • 状态行带 aria-live="polite"；卡片是 button， Tab 可逐个聚焦，Enter / Space 触发。

落地注意

  • 环形要自定义绘制。QPainter 画底环 + 进度弧，开 Antialiasing， 用 16ms QTimer 或 QPropertyAnimation 驱动一个 float progress（linear）； 这样环端点是连续角度，不会被像素取整成一跳一跳。
  • 不要用 QProgressBar.setValue 驱动这个环。qfluentwidgets 的 ProgressBar.setValue() 内部每次都会 ani.stop(); setEndValue(v); setDuration(150); ani.start()； 50ms 一调等于 150ms 的动画永远走不完就被重启，值会滞后。
  • 若保留底部进度条：用 setUseAni(False) 后直接更新， 或绕过 setValue 用 setVal(float)，由 16–50ms 的 QTimer 驱动。
  • 比例用 maxTime：updateTimer() 已经记下首次 adjustedTimeLeftInPhase 作为 maxTime；本页按 45 秒示意， 不要照抄常量。
  • 主题色走 themeColor()：现在 setCustomBarColor("#009688", "#009688") 写死了， 跟用户自定义主题色脱节；本页按默认 #009faa 呈现。
  • 英雄名要传进窗口：updateBenchChampions() 目前只给 {championId, icon}；名称可取自 ChampionAlias 本地缓存或 LCU。
  • 状态色建议进 StyleSheet.ARAM_BENCH 的 dark/light 两套 QSS； 成功提示 4 秒后回落到中性，失败要保留到下次成功或用户再操作。
  • 尺寸要同步改 setFixedSize() 与 adjustPosition()（含 DPI 换算）；高度变化时重算右下角定位。

取舍与待确认

  • 没写「6/10」容量分母：备选池上限随版本/模式变化， 未核实前只显示「6 位」。
  • 优先目标不分优先级视觉：desiredChampions 是有序 列表，但多目标同时上架时该先抢谁，UI 没表达；本页只标「在池」。
  • 是否显示「当前持有英雄」：大乱斗的交换是「你 ↔ 备选席」， 窗口里没有你当前英雄作参照；客户端左侧本身有显示，要不要重复由你定。
  • 高度自适应：1 行 358 / 2 行 448。实机若不想动高度， 回到固定 448 即可，内容完整，只是单行时下方留白。
  • Mica 只是示意：页面里的半透明窗口是对 Mica 的模拟， 实机是系统壁纸模糊，明暗观感会随桌面变化。
